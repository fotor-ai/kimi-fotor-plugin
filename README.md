# Fotor for Kimi Code

This repository will receive exported Fotor plugin snapshots for Kimi Code CLI
and Desktop. Plugin implementation remains maintained in the central Fotor source
repository; this repository is a distribution destination.

The default branch currently contains only this bootstrap notice and the license.
It does not contain an installable plugin. Do not install from the bare repository
address until the complete root package is published and verified. Test-channel
availability will be announced separately; no release is implied by this notice.

See [Fotor](https://www.fotor.com/) and [LICENSE](LICENSE).
